# dashboard-ui-review

## When to use

Reviewing a UI change before merge.

## Inputs

The UI change under review.

## Steps

1. Check the three core journeys still work (see `docs/BRIEF.md`).
2. Check keyboard navigation, focus states and contrast.
3. Check every displayed number traces to a record field.
4. Check the partial-gravity gap is still visible.
5. Check loading, empty and error states.

## Output

Checklist with pass/fail and notes.
