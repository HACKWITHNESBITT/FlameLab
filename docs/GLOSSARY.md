# GLOSSARY

| Term | Meaning |
| --- | --- |
| ACME | Advanced Combustion via Microgravity Experiments; six experiments with gaseous-fuel flames, run with the same modular hardware in the CIR |
| BASS, BASS-II | Burning and Suppression of Solids; studies of solid material flammability and suppression, run in the MSG |
| BRE | Burning Rate Emulator, part of ACME; studies material flammability in still atmospheres as a function of material properties |
| CFI | Cool Flames Investigation; burning droplets of liquid fuel |
| CFI-G | Cool Flames Investigation with Gases; reached the highest oxygen concentrations in microgravity (up to 85% oxygen) |
| CIR | Combustion Integrated Rack on the International Space Station |
| Cool flame | A low-temperature flame; studied in CFI and CFI-G |
| DAFT, DAFT-2 | Dust and Aerosol Measurement Feasibility Test; used a smoke-detection instrument from SAME to detect dust |
| Diffusion flame | A flame that relies on diffusion for its oxygen; typical in microgravity because there is no buoyant flow |
| E-FIELD Flames | Electric-Field Effects on Laminar Diffusion Flames, part of ACME; mimics partial gravity through the electric field's effect on flame ions |
| FLEX, FLEX-2 | Flame Extinguishment Experiment; burning droplets, with atmosphere dilution by carbon dioxide and helium |
| FM2 | Flammability of Materials on the Moon; expected future partial-gravity experiment |
| Flammability limit | The conditions (for example oxygen concentration and airflow) beyond which a material will not sustain burning |
| LUCI | Lunar-g Combustion Investigation; expected future partial-gravity experiment |
| MDCA | Multi-user Droplet Combustion Apparatus; hardware in the CIR used for FLEX, FLEX-2 and CFI |
| Microgravity | Free fall conditions with very little apparent gravity, such as on the ISS |
| MSG | Microgravity Science Glovebox |
| Partial gravity | Gravity between zero and Earth normal, such as the Moon and Mars; no PSI combustion data exists yet |
| Pillars | Prevention, detection and suppression, the three focus areas of spacecraft fire safety |
| PSI | NASA Physical Science Informatics database |
| psi | Pounds per square inch; Earth sea-level pressure is 14.7 psi |
| Saffire | Spacecraft Fire Safety Demonstration; large-scale fire experiments (Saffire-I, -II, -III in this project) |
| SAME, SAME-R | Smoke and Aerosol Measurement Experiment; fire detection studies |
| SI | Super intelligence layer; the system that summarizes, ranks and interprets investigations |
| SLICE | Structure and Liftoff In Combustion Experiment |
| SPICE | Smoke Point In Co-flow Experiment; its fan-driven flow duct is reused by BASS, BASS-II and SLICE |
| Spacesuit atmosphere | 100% oxygen at 4.3 psi |
| Moon base atmosphere (expected) | Oxygen 30% or more at 10.2 psi or less |
| Citation token | A marker such as `[rec:bass-ii#test_conditions.oxygen_percent]` linking an SI sentence to a record field |
| Fail closed | If verification cannot confirm something, do not show it |
| Lens | A user-selected emphasis (prevention, detection, suppression) that changes scoring weights |
