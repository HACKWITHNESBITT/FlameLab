# sources

Downloaded secondary sources (PSI packages are curated separately per
`docs/DATA_OPERATIONS_GUIDE.md`). `.txt` files are `pdftotext` working copies
for curator extraction; the PDFs are the cited artifacts.

| Directory | Contents | Origin |
| --- | --- | --- |
| `glenn/` | 8 investigation fact-sheet PDFs (ACME, BASS, DAFT, FLEX, SAME, SPICE, Saffire, SLICE) | NASA Glenn combustion science page |
| `guide/` | ISS Researcher's Guide to Combustion Science mini-book (2015) | nasa.gov |

Cite as `data/sources/<dir>/<file>.pdf` plus the section name in record `source` objects.
